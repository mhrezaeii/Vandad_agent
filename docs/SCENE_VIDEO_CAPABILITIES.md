# Initial KIE video-provider and native-audio capability contract

The initial production scope intentionally registers KIE.ai Grok Imagine only.
Alternative video APIs, gateways and model hosts are not configured, selectable,
or called by the application. Their quality and cost will be evaluated in a
later phase before any adapter is added.

## Runtime catalogue

The endpoint GET /api/v1/providers/scene-video/models exposes the capability
contract for registered scene-video providers. In this release, it returns KIE
when SCENE_VIDEO_KIE_API_KEY is configured.

## Active KIE model

- Provider: kie
- Model: grok-imagine/image-to-video
- Input: exactly one character reference image plus the approved scenario prompt
- Duration: 6–30 seconds, whole seconds
- Resolution: 480p by default; 720p and 1080p are configurable
- Aspect ratio: derived by KIE from the uploaded reference image
- Audio: generated by KIE (provider-native audio) and preserved in the returned MP4; no local TTS/lip-sync replacement
- Generation mode: single_shot by default; one approved scenario maps to one paid task
- Provider fallback: disabled; no automatic switch to another vendor

A single-shot project without a valid reference image fails before budget
reservation and before a paid request. The character image is uploaded as the
original source image; the application does not run an image-editing step on it.

## Test-only provider

The local mock implementation exists only for deterministic unit and pipeline
tests. It is not registered by the normal KIE runtime and cannot be selected
from the production Content Studio.

## Future provider evaluation

Any additional provider must be evaluated in a separate phase against accepted
output quality, Persian speech quality, reference-character fidelity,
successful completion rate, retry behavior, latency, actual cost per accepted
video, and quota/availability. It must not be added to .env.example or the
runtime registry before that evaluation is approved.
