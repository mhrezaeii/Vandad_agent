# اسکرین‌شات‌های پلتفرم‌ها

اسکرین‌شات‌های واقعی هر پلتفرم را در پوشه همان پلتفرم بگذارید.
این تصاویر در مرحله مونتاژ (FFmpeg) روی ویدیوی AI قرار می‌گیرند تا UI واقعی محصول نمایش داده شود.

## نام‌گذاری پیشنهادی

- `01.png`، `02.png`، ... (ترتیب نمایش)
- یا نام توصیفی: `dashboard.png`، `projects.png`، `tasks.png`، `chat.png`، `files.png`

## نکات

- عمودی یا افقی مهم نیست؛ در مونتاژ به اندازه قاب ۹:۱۶ fits می‌شود.
- PNG یا JPG.
- هر چه کیفیت بالاتر، خروجی تمیزتر.
